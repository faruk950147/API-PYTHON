✅ 1. Direct VS Code (limited)

VS Code দিয়ে open করলে শুধু unreadable data দেখাবে:

এটা useful না
✅ 2. Best way (recommended)
Terminal দিয়ে inspect:
celery -A config inspect scheduled

বা

celery -A config inspect active
✅ 3. Logs দেখো (best method)
celery -A config beat --loglevel=info

এখানে তুমি দেখতে পাবে:

কোন task কখন run হবে
কোন task trigger হচ্ছে
✅ 4. Redis-based monitoring (advanced)

যদি Redis ব্যবহার করো, তাহলে:

Flower dashboard ব্যবহার করা যায়
Real-time task monitoring করা যায়
pip install flower
celery -A config flower

Open:

http://localhost:5555
